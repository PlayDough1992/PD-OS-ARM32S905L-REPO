# PD-OS ARM32 Official Package Repository (S905L)

Official software repository for PD-OS running on Amlogic Meson S905L ARM32 architecture.

## Available Packages

| Package | Version | Creator | Category / Description |
| :--- | :--- | :--- | :--- |
| `pd-calc` | 1.0.0 | PlayDough1992 | Standard and scientific desktop calculator |
| `pd-paint` | 1.2.0 | PlayDough1992 | Pixel drawing and graphics canvas editor |
| `pd-clock` | 1.0.1 | PlayDough1992 | Timezone clock, alarm, and precision timer |
| `pd-notes` | 1.1.0 | PlayDough1992 | Lightweight desktop scratchpad and notes |
| `pd-sysmon` | 2.0.0 | PlayDough1992 | Real-time CPU, RAM, and hardware metrics |
| `pd-terminal` | 1.5.0 | PlayDough1992 | Advanced terminal with VT100 colors & tabs |
| `pd-nettools` | 1.0.0 | PlayDough1992 | Network toolkit: Ping, DNS lookup, HTTP probe |

## Installation

Inside PD-OS Terminal:
```bash
elev pdpm update
elev pdpm install pd-paint
elev pdpm install pd-calc
```
